# Example prompts

Ask these in any client with the LLMBenchmark.ai server connected.

- "Which model should I use to refactor a React app under $5 per million output tokens?"
- "What is the best open-weight model for math with at least a 128k context window?"
- "Compare Claude Opus and GPT-6 Astra for coding."
- "Which models are cheapest on output price from DeepSeek?"
- "Which model is best for agentic tool use with a 200k context window?"
- "Show the top 10 models on the reasoning leaderboard."
- "What does Gemini cost per million input and output tokens compared with Claude Sonnet?"
- "Which categories can you rank models on, and which task keywords pick each one?"
